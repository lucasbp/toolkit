# Toolkit pessoal

Repositório público de LucasBP. Cada pasta representa um módulo independente; não criar repositório novo para cada ferramenta.

- Seguir também o AGENTS.md do módulo alterado.
- Usar worktree própria para mudanças e PRs.
- Código sem comentários. Explicações ficam na documentação.
- Não incluir integrações, credenciais, configuração privada ou código específico de empresas.
- Código público, push e publicação exigem autorização do usuário. A criação pública inicial e a distribuição do módulo DataGrip foram autorizadas em 2026-11-04.
- Publicações por módulo usam tag com prefixo, build validado e ZIP/checksum como assets da Release. Não confundir Source code com pacote instalável.
- Artefatos locais ficam em artifacts, ignorados pelo Git.
